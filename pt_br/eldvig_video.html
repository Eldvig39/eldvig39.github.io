Instalação, atualização, remoção, etc. do programa "Eldvig":

Sistema operacional Windows

1. Instalando o Java JDK 22 do programa Oracle e Eldvig em um computador de 64 bits com sistema operacional Windows 7, 8, 9, 10, 11.

2. Atualizando todas as versões do programa Eldvig em um computador com sistema operacional Windows.

Sistema operacional Linux

1. Atualizando todas as versões do programa Eldvig em um computador com o sistema operacional Linux.
